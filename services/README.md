# Services

This directory contains the various microservices that make up the Gen AI Work Buddy application.

*   [auth-service](./auth-service/README.md) - Handles user authentication and onboarding.
*   [integration-service](./integration-service/README.md) - Manages connections to third-party tools like Google Calendar, Jira, and Confluence.
*   [meeting-service](./meeting-service/README.md) - Manages meeting attendance and participation logic.
*   [notification-service](./notification-service/README.md) - (Conceptual) Handles system notifications via a message queue.
*   [ai-processing-service](./ai-processing-service/README.md) - Handles core AI tasks (placeholder).
